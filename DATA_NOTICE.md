# Data notice

All provider accounts, referrals, representatives, intake owners, outreach activities, targets, and workflow events are generated synthetic portfolio data. No patient-level personal identifiers, employer exports, confidential CRM records, or actual clinical records were used. The fictional organization name is a scenario label and does not imply affiliation with an existing organization.

The generation manifest intentionally reveals the injected problems for testing. It must not be used as an input to the reporting transformations; `02_build_reporting.sql` operates on raw source tables only. AI assisted this starter package. Review, reproduce, adapt, and explain the implementation before presenting the finished case study.
